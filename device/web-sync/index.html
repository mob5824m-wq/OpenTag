Send plain text or a web URL to your OpenTag device over Bluetooth LE. The device can write standard NDEF records to a supported NTAG215. It does not accept tag images or proprietary data files.

This page sends only the selected text or URL note. It never reads or imports raw NFC tag memory.
Add a note

Only ordinary text and HTTP(S) URLs are supported. Maximum 200 UTF-8 bytes.

Binary tag dumps (.bin), encrypted data, and arbitrary file uploads are intentionally unsupported.

Device response

Connect to OpenTag to sync a note.

OpenTag is an independent open-source project. NFC write operations replace the existing user NDEF area on the selected NTAG215. Confirm on the device before writing; always use tags you own or are authorized to program.
