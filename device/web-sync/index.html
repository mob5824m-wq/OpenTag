NDEF note

Plain text or HTTP(S) URL, up to 200 UTF-8 bytes. Written to NTAG215 tags or emulated as a virtual tag.

Amiibo library

Upload a .zip, loose .bin dumps, or Flipper Zero .nfc files from your own collection — any layout (532/540/572 bytes, padded, or with an N2-style header) is normalized in your browser, validated, then copied to the device over BLE. Nothing is uploaded to any server.

On device

Use only backups of amiibo you own. Amiibo data is Nintendo proprietary; this page and the device never bundle or generate it — you supply your own dumps.

Amiibo signing keys

To write a dump to a physical NTAG215, the device re-signs it (TagMo-style) with your unfixed-info.bin and locked-secret.bin key files — the same pair TagMo loads. A combined 160-byte retail key file also works. Files are identified by their embedded type string, stored in the device's NVS, and never bundled with this project or sent anywhere else.

Key state: unknown — connect and check

Only use key files you legally extracted yourself. Uploading them is your responsibility.

OpenTag is an independent open-source project. NFC writes replace the existing NDEF area of the selected NTAG215. Confirm on the device before writing; only use tags you own or are authorized to program.
