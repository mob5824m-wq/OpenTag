OPENTAG — DEVICE UI PREVIEW

Simulation of the firmware's OLED interface (SSD1351, 128×128) for design testing. This page talks to no hardware — every screen, color and pixel position is a faithful port of drawScreen() in device/src/main.cpp. UP/DOWN move, OK selects (hold ~1 s for a long press), BACK cancels or exits whatever screen you're on. Hold OK at the menu to power off (BACK cancels within the window); hold OK while off to power back on.

The four round buttons mirror the physical device (UP · DOWN · OK · BACK, west→east on the shell). "Simulate: tap NTAG215" places a tag on the antenna — used by the note-write screen, and (advanced) the amiibo write screen. "Console taps tag" imitates a Switch reading the emulated tag.

An NDEF note is a short text or web link stored on the device: sync one from the BLE sync page, then "Write NDEF note" copies it to a blank NTAG215 tag (any NFC phone can read it) or "Emulate NDEF note" pretends to be that tag. "Clear NDEF note" wipes the stored note. BACK is the universal exit: cancel a scan, stop emulation, skip the lock prompt, or leave the amiibo library.
